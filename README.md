# Solace — Integrated Living

An Astro homepage for Solace, a luxury residential technology integrator. The visual direction follows the supplied Terraza Balear reference’s editorial pacing and image-led structure, with original Solace copy, branding, and generated photography.

## Start developing

    npm install
    npm run dev

Astro serves the site at http://localhost:4321. Build with npm run build and preview the production output with npm run preview.

## Project map

- src/pages/index.astro — homepage sections and project carousel content
- src/pages/consultation.astro — consultation landing page and guided project inquiry
- src/components/SiteHeader.astro — centered logo and split navigation shared across pages
- src/layouts/Layout.astro — page metadata and shared document shell
- src/styles/global.css — responsive site styles
- public/images/ — optimized WebP photography used by the site
- public/favicon.svg — Solace favicon
- media-manifest.json — generated media source and placement notes

The sample contact address hello@solace.studio is a placeholder. Replace it with Solace’s real contact address before launch. The generated project images are representative template visuals, not documentation of completed client projects. Connect a real video asset if the hero is later changed to a film.
